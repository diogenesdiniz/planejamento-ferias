# Skills

Ainda sem nenhuma skill própria criada. Os critérios usados para montar roteiro (horário de funcionamento e compromissos fixos primeiro, depois proximidade, depois luz do dia, depois tempo real de deslocamento) hoje vivem embutidos nas instruções do agente `planejador-viagem` (`../agents/planejador-viagem.md`).

Se esses critérios crescerem a ponto de precisar ser reaproveitados por mais de um agente, ou consultados fora do fluxo de planejamento (por exemplo, por um agente de revisão que audita um roteiro já pronto), esse é o sinal para extraí-los daqui para uma skill própria, em `criterios-roteiro/SKILL.md`.
